# BG Assistant

一个常驻 Windows 托盘的桌面小助手：锁定、遮屏、Chrome 多开、路由管理、端口转发、沙箱启动，都收在托盘菜单里。

单文件绿色版，不安装、不写系统服务、不联网。

---

## 功能一览

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| 锁定 | 托盘 › 锁定 | 立即锁定 Windows（等同 `Win+L`） |
| 遮屏 | 托盘 › 遮屏 | 短暂离开工位：锁住键鼠，屏幕保持原样显示工作内容，盲打密码解锁 |
| Chrome 多开 | 托盘 › 系统 › Chrome多开 | 每个多开一套独立数据目录，同时登录多个 Chrome 账号（可配代理 / UA / 独立窗口） |
| 路由管理 | 托盘 › 系统 › 路由管理 | 图形化增删静态路由、查看系统路由表（需管理员） |
| 端口转发 | 托盘 › 系统 › 端口转发 | 图形化管理 `netsh` 端口转发规则，增删改查（需管理员） |
| 沙箱 | 托盘 › 沙箱 | 一键启动 Sandboxie 沙箱里配好的程序 |
| 开机自启 | 托盘 › 设置 | 登录 Windows 后自动运行 |
| 锁屏密码 | 托盘 › 设置 | 设置 / 修改「遮屏」的解锁密码 |

---

## 开始使用

1. **双击 `BGAssistant.exe`**，不需要安装。首次运行会在 exe 同目录生成配置文件 `BGAssistant.ini`。
   （程序就是单个 exe，放在任意目录都能跑；仓库里若没有现成 exe，按 [BUILD.md](BUILD.md) 自行构建。）
2. 托盘区出现**太极图标**，**左键单击**它弹出菜单（右键也可以）。
3. 建议先做两件事：在「设置」里勾选**开机自启**、设一个**锁屏密码**。
4. 退出：菜单最下面的**退出**。

> 程序没有主窗口，双击 exe 后只在托盘出现图标。如果没看到，点一下任务栏右下角的 `^` 展开隐藏图标。
>
> 把 exe 挪到别的位置后，需要重新勾选一次「开机自启」——自启项里记的是 exe 的绝对路径。


| 菜单项 | 作用 |
| --- | --- |
| 设置 | 开机自启、锁屏期间保持屏幕常亮、修改锁屏密码 |
| 系统 › Chrome多开 | 启动配好的 Chrome 多开；「多开管理…」里增删改（不需要管理员） |

| 系统 › 端口转发 | 打开端口转发窗口（会请求管理员权限） |
| 沙箱 › … | 启动对应沙箱里的程序（内容来自 Sandboxie 配置） |
| 锁定 | 立即锁定系统 |
| 遮屏 | 启动神隐遮屏 |
| 退出 | 结束程序 |

## 功能详解

### 锁定

点一下立即锁定 Windows，解锁用系统账户的密码 / PIN / 指纹。

### 遮屏（神隐锁屏）

适用场景：**工作期间临时离开工位**——起身倒杯水、开个短会、上个洗手间，几分钟就回来。

它不会把电脑切到锁屏界面，而是让屏幕**继续显示你离开前的画面**（正在写的文档、正在看的代码都在），
看起来就像人还在座位上、马上回来；同时键盘鼠标被锁住，别人碰不了你的电脑。
配合「设置 › 锁屏期间保持屏幕常亮」，还能避免离开一会儿屏幕就黑掉。

和系统锁屏（`Win+L`）的区别：

| | 系统锁屏 | 遮屏 |
| --- | --- | --- |
| 屏幕显示 | 切到锁屏界面，看不到原来的工作内容 | 保持原样，仍显示你离开前的画面 |
| 息屏 | 停留一会儿后自动黑屏 | 可选保持常亮（设置里勾选） |
| 给别人的感觉 | 明确「人走了」 | 像人还在，只是暂时没动 |

用法：

- 解锁只要**盲打密码**——屏幕上没有输入框，直接敲，输对就自动解开，不用回车、不用点任何地方；
- 输错会自动清空，从第一个字符重新开始；
- 锁定期间屏蔽 `Win`、`Ctrl`、`Alt` 及其组合键（`Win`、`Alt+Tab`、`Ctrl+Esc`、`Alt+F4` 等），鼠标被拉回屏幕中央；
- 锁定时屏幕中间闪一下红色「已锁定」，解锁时闪绿色「已解锁」，约 1 秒消失；
- 托盘区会多出一个「锁」图标，解锁后消失，主程序的太极图标不受影响；
- **只在主屏生效**：多显示器时副屏不受影响；
- 首次使用前要先在「设置 › 锁屏密码」里设一个密码——没设密码时点「遮屏」会提示，并直接打开设置窗口。

> ⚠️ 它挡的是「顺手动一下」，不是「有意破解」：任务管理器结束进程、`Ctrl+Alt+Del`、`Win+L` 这类系统级操作拦不住。
> 真要离开很久或防人翻看，还是用系统自带的锁屏。

### 系统 › Chrome 多开

适用场景：同一个网站要同时登录多个账号（工作号 / 私人号、多个游戏号），又不想来回切换。每个多开用**独立的数据目录**，等于各开一个干净的 Chrome。

点这个菜单不弹 UAC：多开是普通权限就能做的事，管理窗口和 `chrome.exe` 都以当前用户身份启动。

「系统 › Chrome多开」里直接列出配好的多开，点名字就启动；最后一项「多开管理…」打开管理窗口：

| 按钮 | 作用 |
| --- | --- |
| 新建 | 填名称和选项创建多开，**名称必填**（同时作为数据子目录名） |
| 编辑 | 改选中项的配置；改名或换目录时，确定后会问你是否迁移已有数据 |
| 复制 | 参数照搬一份，数据目录是新的，登录状态干净 |
| 删除 | 只删配置，**不删数据目录**；以后新建同名多开还能接着用 |
| 上移 / 下移 | 调整选中项的顺序；也可以直接拖动行，托盘菜单按这个顺序排列 |
| 启动选中 | 立即拉起这个多开（双击列表行是编辑，避免误触） |

列表顺序就是托盘菜单里的顺序：按住某一行拖动，或者用「上移 / 下移」调整，改完立即生效。

窗口中间显示选中项实际执行的命令行，可以复制到 cmd 里排查启动问题。

**数据位置**：默认是 exe 同目录的 `chrome多开` 文件夹，新建的多开在下面有一个同名子目录：

```
BGAssistant.exe
chrome多开\
├── 工作号\        ← 「工作号」这个多开的数据
└── 游戏号\        ← 「游戏号」这个多开的数据
```

每个多开**新建时就把数据目录的绝对路径记进配置**（列表里的「数据目录」列能看到），之后不会因为改了全局位置而漂移：

- 新建 / 编辑时可以点「浏览…」给单个多开指定别的位置；目录已存在就直接沿用里面的登录状态。
- 编辑已有多个开时，如果它的目录和全局位置不一致，「用全局目录」按钮可以一键改回 `<全局位置>\<名称>`。
- 只要数据目录变了（改名、浏览、用全局目录都算），点「确定」后会问：**是否把旧目录的数据迁移到新目录**。选「是」会把文件搬过去、成功后删除旧目录（迁移前先关掉对应的 Chrome 窗口）；选「否」只改配置，旧目录原样保留。
- 窗口底部的「修改…」改的是**全局**位置：已经有多个开时会问是否把它们一起迁过去；选「否」只影响以后新建的多开。

把全局位置指到以前 bat 放数据的目录，再新建同名多开，就能直接沿用原来的登录状态。

选项对应原来 bat 脚本里的参数：

| 选项 | 对应参数 |
| --- | --- |
| 代理方式：指定代理服务器 / 不使用代理 | `--proxy-server="..."` / `--no-proxy-server`；选「使用系统代理」则不传任何代理参数 |
| 指定 User-Agent | `--user-agent="..."` |
| 独立窗口模式运行 | `--app="https://..."`（不写协议时按 https 补全） |
| 指定窗口大小 | `--window-size=宽,高` |
| 指定窗口位置 | `--window-position=x,y` |
| 启动最大化 / 强制全屏 / 演示（无边框全屏） | `--start-maximized` / `--start-fullscreen` / `--kiosk`，三者互斥 |
| 强制缩放 150% | `--force-device-scale-factor=1.5` |
| 指定窗口名称（仅首次生效） | `--window-name="..."` |

浏览器缓存单独放在 `%TEMP%\<名称>`（`--disk-cache-dir`），不占数据目录的空间，拷走数据目录时也不会带上几百 MB 缓存。配置存在 `BGAssistant.ini` 的 `[ChromeMultiOpen]` 分组里。

> 只有在 `%LOCALAPPDATA%\Google\Chrome\Application\` 或 `Program Files`（含 x86）下找到 `chrome.exe` 时，这个菜单才会出现。

### 系统 › 路由管理

适用场景：一台机器有多块网卡 / 多个网关时，让不同网段走不同出口。比如内网走有线、外网走无线，或者让某个网段强制走 VPN 网关。

点这个菜单会弹 **UAC**——修改系统路由表需要管理员权限。同意后会打开路由管理窗口，主程序的托盘图标不受影响；关掉窗口，那个管理员进程也就退出了。点「否」则什么都不做。

窗口里三行输入：

| 字段 | 填什么 |
| --- | --- |
| 需要配置的网段 | 目标网段，如 `192.168.5.0`；配外网网关时填 `0.0.0.0` |
| 该网段的子网掩码 | 按网段自动填（A/B/C 类），**手动改过之后就不再自动覆盖** |
| 该网段要使用的网关 | 这个网段的流量从哪个网关出去 |

- 勾选**是否长效路由**，重启后规则依然有效；不勾选则重启后失效。
- **添加路由**：写入一条路由。
- **删除路由**：按网段删除，掩码和网关会被忽略（只需填网段）。
- 三个 IP 输入框都是四段式：输满一段自动跳到下一段，也可以用 `→` `Tab` 或直接打点号切换，支持直接粘贴整段 IP。
- **显示系统路由表**：打开原生表格，列出目标网络 / 子网掩码 / 网关 / 接口 / 跃点数 / 长效，右上角可刷新。表里网关显示「在链路上」表示该网段是直连，不经过网关。

> 这里改的是真实的系统路由表，删错网关可能导致断网。拿不准时先点「显示系统路由表」看看现状，再动手。

### 系统 › 端口转发

适用场景：让别的机器、WSL 或虚拟机通过本机的一个地址，访问只监听在本机的服务。典型例子是把 `192.168.81.1:7890` 转发到 `127.0.0.1:7890`，让 WSL 里的程序用上 Windows 上跑的代理。

背后就是 Windows 自带的 `netsh interface portproxy`（v4tov4）。规则存在注册表里，重启后依然有效；只支持 TCP。

点菜单同样会弹 **UAC**，同意后打开窗口。上半部分是当前已有的转发，下半部分填参数：

| 字段 | 填什么 |
| --- | --- |
| 侦听地址 | 本机已有的 IP，如 `192.168.81.1`；填 `0.0.0.0` 表示所有网卡 |
| 侦听端口 | 外部访问进来的端口，1-65535 |
| 连接地址 | 要转发到哪个地址，通常填 `127.0.0.1` |
| 连接端口 | 目标服务实际监听的端口 |

- **添加转发**：按上面四项新增一条，立即生效。
- **更新选中**：先在列表里选中一行，改完参数再点。`netsh` 的 `set` 只能改连接地址/端口，还有不重新绑定监听的情况，所以这里按「删旧 + 加新」重建规则；改侦听地址/端口时先加新再删旧，尽量不断流。
- **删除选中**：删掉选中的那条，端口立刻停止转发。
- 窗口底部会显示 IP Helper 服务（`iphlpsvc`）的状态——这个服务没跑，规则存在也不会转发。

> 侦听地址必须是本机真实存在的 IP，`0.0.0.0` 表示所有网卡。填 `0.0.0.0` 时别再把同一端口转回本机——它会占住本机所有 IP，转出去的连接又命中自己的侦听，形成死循环，这种配置窗口会直接拦下。删错规则不影响正常上网，重新添加即可。

### 沙箱（Sandboxie）

前提：装了 [Sandboxie-Plus](https://sandboxie-plus.com/)，并且 `C:\Windows\Sandboxie.ini` 里有配好的 `RunCommand`。

- 菜单内容**全部来自 Sandboxie 配置**，程序本身不保存任何沙箱列表；
- 一个沙箱只配了一条 `RunCommand`，菜单显示沙箱名；配了多条时显示为 `沙箱名|键名`，避免重名分不清；
- 按名字字母序排列（忽略大小写）；
- **每次弹出菜单都会重新读取配置**，改完 ini 不用重启程序；
- 没装 Sandboxie、或一个 `RunCommand` 都没配时，整个「沙箱」菜单不显示；
- 菜单第一项「显示启动命令」会列出每个沙箱最终执行的命令行，排查启动问题时用。

沙箱配置里写的是**沙箱内的路径**，启动时会自动映射回真实路径：

| ini 里的写法 | 实际启动 |
| --- | --- |
| `%BoxRoot%\drive\C\Program Files\WeGame\wegame.exe` | `C:\Program Files\WeGame\wegame.exe` |
| `%BoxRoot%\user\current\AppData\Local\Programs\Apifox\Apifox.exe` | `C:\Users\<你的用户名>\AppData\Local\Programs\Apifox\Apifox.exe` |
| `D:\Programs\WinMerge\WinMergeU.exe` | 原样使用（本来就是真实路径） |

即：`%BoxRoot%\drive\<盘符>\...` → `<盘符>:\...`，`%BoxRoot%\user\current\...` → 当前用户目录，其余原样。

## 文件与注册表

程序只碰这两处，其余什么都不写：

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 配置文件 | exe 同目录 `BGAssistant.ini` | 锁屏密码（AES 加密后存 Base64）、是否保持屏幕常亮、Chrome 多开配置（`[ChromeMultiOpen]`） |
| Chrome 多开数据 | 每个多开新建时记录自己的绝对路径，默认 `exe 同目录\chrome多开\<名称>\` | 各多开的登录状态；删除多开配置不会删这里，改目录时可以选择是否迁移 |
| 开机自启 | `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` | 值为 exe 绝对路径；取消勾选即删除该项 |

配置文件随程序走：把 exe 和 ini 一起拷到别的机器，密码设置也会跟着过去；只拷 exe 则视为首次运行、需要重新设置密码。

## 常见问题

**点了「遮屏」，提示「尚未设置解锁密码！」**
先去「设置 › 锁屏密码」设一个密码，再点遮屏。

**忘了遮屏密码怎么办？**
退出程序，用记事本打开 exe 同目录的 `BGAssistant.ini`，删掉 `[LockScreen]` 下的 `Password=` 那一行（或直接删掉整个 ini），重新启动程序后再设一个新密码。删除配置文件不影响任何系统设置。

**点「路由管理」「端口转发」弹 UAC，能不让它弹吗？**
不能。改系统路由表、改端口转发规则都必须有管理员权限，这是 Windows 的限制。点「否」不会执行任何操作。

**端口转发加好了，但连不上？**
先看窗口底部 IP Helper 服务（`iphlpsvc`）是否在运行；再确认侦听地址填的是本机真实存在的 IP（`0.0.0.0` 表示所有网卡），以及侦听端口没被别的程序占用。`netsh` 的转发只支持 TCP。

**路由表里的「在链路上」是什么意思？**
表示这条路由是直连网段，网关为 `0.0.0.0`，数据不经过网关转发（对应 `route print` 里的 `On-link`）。

**托盘里的「沙箱」菜单不见了？**
需要装 Sandboxie-Plus，且 `C:\Windows\Sandboxie.ini` 里至少有一个带 `RunCommand` 的沙箱。配置好后重开一次托盘菜单即可，不用重启程序。

**托盘里的「Chrome多开」菜单不见了？**
只有找到 `chrome.exe` 才会显示。程序会查 `%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe` 和 `Program Files`（含 x86）下的同名路径；Chrome 装在别处、或装的是 Chromium / Edge 时不会出现。

**以前 bat 脚本的多开数据能接着用吗？**
能。两种方式：在「多开管理」里把全局数据位置指到原来放数据的目录（bat 里 `%cd%` 那个目录），再新建同名的多开；或者在编辑已有多个开时点「浏览…」直接选中那个目录（选「不迁移数据」即可）。名称对不上时建个同名的就行。

**托盘图标一直在转，正常吗？**
正常，那是太极动画，表示程序正在运行。

**双击 exe 没反应？**
它没有主窗口，启动后只出现在托盘。检查一下任务栏右下角的 `^` 隐藏图标区。

**遮屏一会儿屏幕就黑了？**
系统电源计划到了时间会关显示器。想要遮屏期间一直亮着，就在「设置」里勾选「锁屏期间保持屏幕常亮」。
